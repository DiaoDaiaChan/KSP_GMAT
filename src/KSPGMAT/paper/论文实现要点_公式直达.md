## 1. 基石｜Izzo 兰伯特求解器《Revisiting Lambert's Problem》(2015)

> 即 `kep3::lambert_problem` / `pykep_lambert_solve`。全篇用 Lancaste-Blanchard 变量 `x,y`，Householder-4 迭代，Gooding 代数重建速度。

### 1.1 记号
- 输入 `r1, r2, t, μ`；弦长 `c=|r2−r1|`；半周长 `s=(r1+r2+c)/2`；相角 `cosθ=(r1·r2)/(r1 r2)`；`a_m=s/2` 最小能量半长轴。
- **核心不变量**：`λ=√(r1r2) cosθ / s`，`λ²=1−c/s`。（λ 相同 ⇒ 所有解等价）
- **非量纲时间**：`T=√(μ/a_m³)·(t2−t1)`。

### 1.2 统一 TOF 方程（所有情形单/多圈、椭圆/双曲）
$$\boxed{T=\frac{1}{1-x^{2}}\left(\frac{\psi+M\pi}{\sqrt{|1-x^{2}|}}-x+\lambda y\right)}$$
其中 `x=cos(α/2)`、`y=cos(β/2)=√(1−λ²(1−x²))`；`x=0⇒最小能量椭圆`、`x=1⇒抛物线`；`M` 圈次，双曲强制 `M=0`。

### 1.3 重要特值
- `x=0`：`T(0)=arccos λ + λ√(1−λ²) + Mπ`
- `x=1`（抛物线）：`T(1)=2/3(1−λ³)`
- 近 `x→1` 用 **Battin 超几何级数**消相消：`η=y−λx, S1=½(1−λ−xη), Q=(4/3)·₁F₂(3,1;5/2;S1), 2T=η³Q+4λη`

### 1.4 时间导数（一阶/二阶/三阶，Householder 所需）
$$(1-x^{2})T'=3Tx-2+2\lambda^{3}\frac{x}{y}$$
$$(1-x^{2})T''=3T+5xT'+2(1-\lambda^{2})\frac{\lambda^{3}}{y^{3}}$$
$$(1-x^{2})T'''=7xT''+8T'-6(1-\lambda^{2})\frac{\lambda^{5}x}{y^{5}}$$
边界：`T'(x=1)=⅖(λ⁵−1)`（仅 M=0），`T'(x=0)=−2`。

### 1.5 迭代（Householder 4 阶）
$$x_{n+1}=x_n-\frac{f\big(f'^{2}-\tfrac12 f f''\big)}{f'\big(f'^{2}-f f''\big)+\tfrac16 f''' f^{2}}\qquad f=T(x)-T^{*}$$
收敛判据：M=0 时 `Δx<1e-5`，M>0 时 `Δx<1e-8`；单圈约 2 次、多圈约 3.3 次收敛。

### 1.6 速度重构（Gooding 代数重建）
`ρ=(r1−r2)/c, σ=√(1−ρ²), γ=√(μs/2)`，
$$V_{r,1}=\tfrac{\gamma}{r_1}\big[(\lambda y-x)-\rho(\lambda y+x)\big],\quad V_{r,2}=-\tfrac{\gamma}{r_2}\big[(\lambda y-x)+\rho(\lambda y+x)\big]$$
$$V_{t,1}=\tfrac{\gamma\sigma}{r_1}(y+\lambda x),\quad V_{t,2}=\tfrac{\gamma\sigma}{r_2}(y+\lambda x)$$
合成 `v1=Vr,1·îr,1+Vt,1·ît,1`，`v2` 同理。`λ` 符号（顺/逆行）由 `cross(r1,r2)` 判定。

### 1.7 初猜（多圈无需 Tmin 迭代）
- 单圈分段直线反解 `(ξ,τ)=` 平面（ξ=log(1+x) etc.），改进式 `x0=2T1(T1−T)/(5T(1−λ⁵))+1`（T<T1）。
- 多圈两初猜：`x0l=((M+1)π/(8T))^⅔−1) / ((M+1)π/(8T))^⅔+1)`，`x0r=((8T/(Mπ))^⅔−1)/((8T/(Mπ))^⅔+1)`。
- 工程对照：`retrograde` 布尔 ↔ §1.3 对 λ 取反；多圈完整解需原生接口扩展为 vector 返回。

> **→ MGA 落地点**：`LambertMultiRevs`、`LambertDirection` 直接映射 `T/M` 与 λ 符号；`SolveLambert` 在 `tof≤0 || μ≤0` 拒绝。

## 2. 模块 C｜MCTS 借力链《Interplanetary Trajectory Planning with MCTS》(IJCAI 2015)

> MGA 冲量模型 + 动力飞掠，Lambert 用 Izzo 0 圈解。**只出离散借力链，连续变量交给 Native DE**。

### 2.1 目标函数（最小化总 ΔV）
$$\Delta V_{tot}=\underbrace{\max\big(0,\,|\tilde v_0^-|-v_{LS}\big)}_{\text{发射}}+\sum_{i=1}^{N-2}\Delta V_i+\underbrace{|\tilde v_{N-1}^+|}_{\text{捕获}}$$
质量联系：`ΔV=Isp·g0·ln(mi/mf)`。
TOF 界：`T_i∈[0.1(τ_i+τ_{i−1}), 2(τ_i+τ_{i−1})]`（τ=轨道周期）。

### 2.2 历表网格（把连续时间离散化）
$$G=\Big\{t_0+j\cdot\frac{l\,\tau_i}{360°}\ :\ j\in\mathbb N\Big\},\qquad t_0+\sum T_j+T_i\in G_{P_i}$$
`l∈{90°,45°,22.5°,11.25°}`；11.25° 用于穷尽全局最优。

### 2.3 MCTS 选择策略
- **UCB1**：`arg max_i [X̄_i + Cp·√(ln n/n_i)]`，`Cp=1/√2` 即标准 UCB1。
- **UCB1-Tuned**：`arg max_i [X̄_i + √((ln n/n_i)·min(¼, V_i))]`，`V_i=σ_i²+√(2 ln n/n_i)`。
- **ϵ-greedy**（计算最省，工程默认建议）：以 (1−ϵ) 选当前 max，概率 ϵ 随机。

### 2.4 价值/回报（确定性 → max 估计器）
$$X_j=\max\Big(0,\ \frac{\Delta V_{max}-\Delta V_{tot,j}}{\Delta V_{max}}\Big),\qquad \bar X_i=\max_{j\le n_i} X_j$$
- `ΔV_max=10 km/s` 作为**可行性阈值（到达即终态）**，超此不展开。
- 收敛阈值 ε=50 m/s。
- 同轨迹 Lambert 解唯一 ⇒ 求值确定 ⇒ **不重复求值 + max 估计器**；配套 **Contraction**（全覆盖子树剪除）。

### 2.5 关键参数速查
| 项 | 值 |
|---|---|
| ΔV_max | 10 km/s |
| Cp (UCB1) | 1/√2 标准；Rosetta full 优取 1.8454 |
| ϵ (greedy) | 0.011–0.0406 |
| 预算 N | 5×10⁴（fixed）/ 10⁵（full） |
| 飞掠数/深度 | 5–10 次 / 11–21 |
| 分支因子 | ~500 |
| 发射窗口 | Cassini 200d / Rosetta 365d |
| 全局最优 | Cassini 6.571 km/s、Rosetta 5.887 km/s（full） |

> **→ MGA 落地点**：`MGAMCTSTopologySelector` 用 ϵ-greedy（默认）或 UCB1 选借力链；ΔV 阈值、网格对齐、max 估计器、Contraction 照搬；Lambert 段用 Native 0 圈。注意 MGA 需外补 **ΔV-EGA** 才可能复现 `E–E–M–E–E–67P` 这类真实序列。

## 3. 模块 B｜低推力最优制导 + 代理初筛《Machine Learning and Evolutionary Techniques in Interplanetary Trajectory Design》(2018)

> ⚠️ 该综述**未给出 MGA 的 Δv/v∞/飞掠公式与 `z=[t0,ToF,η]` 编码**；可复用素材集中在**低推力最优控制问题本身**与**代理加速**思想。

### 3.1 动力学（恒比冲核电低推力）
$$\dot r=v,\qquad \dot v=-\tfrac{\mu}{r^3}r+\tfrac{c_1 u}{m}\,\hat i_u,\qquad \dot m=-c_2\,u$$
`c1=T_max`，`c2=c1/(Isp·g0)`；`0≤u≤1, |îu|=1`。

### 3.2 成本泛函（α 同伦：二次→质量最优）
$$J=\alpha\!\int u\,dt+(1-\alpha)\!\int u^{2}\,dt$$
`α=1`→MOC（燃料最优），`α=0`→QOC。**先解 QOC 再递增 α 到 1**是同伦收敛关键。

### 3.3 Pontryagin 最优性条件
哈密顿 `H=λ_r·v+λ_v·(−μ/r³ r + c1 u/m îu)−λ_m c2 u + αu+(1−α)u²`：
- 最优推力方向：`îu*=−λ_v/|λ_v|`
- 最优油门（裁剪）：`u*=clip((c1|λ_v|/m+c2λ_m−α)/(2(1−α)), 0, 1)`
- α=1 开关函数：`S_sw=c1|λ_v|/m+c2λ_m−α`；`u*=1 if S_sw>0 else 0`（bang-bang）
- 横截性：自由时间 `H(t2)=0`；自由末端质量 `λ_m(t2)=0`；自由 a：`2λ_r·r2−λ_v·v2=0`

### 3.4 深度网络表示最优状态反馈 `u*(x)`
- 输入 `x=(r,v,m)`；输出极坐标 `(u,θ,φ)`，`u·[sinθcosφ, sinθsinφ, cosθ]`。
- 网络：**4 隐层 × 200**，隐藏层 ReLU，输出 tanh，Glorot 初始化，输入标准化（均值 0 方差 1）。
- 训练：MSE、Adam、minibatch 64、early-stop（loss<1e-4 持续 50 epochs）。
- 数据生成：**Random Walk**（状态扰动 `x1←x0+x0⊙βγ`，成功加大 γ 失败减半）+ **Homotopy**（α 爬坡）。
- 案例：地火 `m0=1000kg, T_max=0.3N, Isp=2500s`，生成 308,579 个状态-控制对。

### 3.5 代理预筛（SurrogatePreFilter 直接依据）
1. 用采样点训练**转移代价（最优转移质量）回归代理**，对候选 `(t0, 到达历元, 借力链)` 快速粗筛，只对过筛者调昂贵 Native 评估。
2. 监督学习用于**改善初猜**。
3. **聚类剪枝**：把搜索集中到有希望的子区域。

> **→ MGA 落地点**：`MGASurrogatePreFilter` = 代理回归代价 + 粗筛 + 聚类剪枝；连续变量编码/精度全部交给 Native 兜底。

## 4. 模块 D｜G&CNets + BGOE 自愈《Real-Time Optimal Guidance and Control … (G&CNets)》(2020)

> 地金低推力、质量最优取时。核心：**一次 TPBVP + 终端扰动 + 反向积分 = 批量最优样本（BGOE）**，再训练策略/价值双网络。

### 4.1 动力学（修正平根数 EFM）
状态 `x=[p,f,g,h,k,L]`，`m`；`w=1+f cosL+g sinL`，`s²=1+h²+k²`。运动方程（矩阵形式）：
$$\dot{\mathbf x}=\tfrac{c_1 u}{m}\,\mathbf B(\mathbf x)\,\hat i_\tau+\mathbf D(\mathbf x),\qquad \dot m=-c_2\,u$$
（`B` 为 6×3 矩阵，`D=[0,..,√(μp³)/w²]`；`c2=c1/(Isp g0)`）

### 4.2 成本（对数障碍正则化，ε 同伦 0.1→1e-6）
$$J=\int_0^{t_f}\Big\{u-\epsilon\ln[u(1-u)]\Big\}\,dt\quad(\epsilon\to0\text{ → 燃料最优})$$

### 4.3 最优控制（Pontryagin）
- 哈密顿 `H` 与伴随正则方程：`ẋ=∂H/∂λ, λ̇=−∂H/∂x, ṁ=−∂H/∂λm, λ̇m=−∂H/∂m`；自由末端 ⇒ `H=0`。
- 最优推力方向：`îτ*=−Bᵀλ/|Bᵀλ|`
- 最优油门（光滑 bang-bang）：
$$\boxed{u^{*}=\frac{2\epsilon}{2\epsilon+SF+\sqrt{4\epsilon^{2}+SF^{2}}},\qquad SF=1-\tfrac{c_1}{m}|\mathbf B^{T}\boldsymbol\lambda|-c_2\lambda_m}$$
- **Bellman 联系**：`λ=∇_x v`（伴随 = 价值函数梯度）⇒ 由价值网络反推最优控制。

### 4.4 BGOE（最优样例反向生成 —— 自愈库来源）
1. 解一条名义质量最优轨迹（同伦收敛）。
2. 扰动终端 `λ_f^new=λ_f*+δλ`、`m_f^new=m_f*+δm`；**强制 `δλ_L=δλ_mf=0`**；扰动 `δλ` 在半径 ρ 球内随机。
3. 由自由时间条件**标量求根 `H_f(δL)=0`** 定 `L_f^new`。
4. 反向数值积分正则方程 ⇒ 新最优轨迹，采样入库。
5. **Sundman 变换**保证沿轨道均匀采样：`dt=√(a/μ)·r dθ_s`。
- 增益：穷举需数年 → BGOE 约 6 小时；发布 7 库共 ~400 万最优转移。

### 4.5 网络与损失
- 策略网络（3 隐层×200）预测 `(u_N, d_r,d_t,d_n)`；价值网络（9 隐层×200 / 3 隐层×1000）预测剩余质量 `J_N≈v`。
- 损失：`l_policy=⟨(u_N−u*)²+(1−îN·î*)⟩`；`l_vf=⟨(J_opt−J_N)²⟩`；`l_λ=⟨((λ)_opt−∇_xJ_N)²⟩`；`l_H=⟨H(x,m,∇_xJ_N,u*)²⟩`；`l_u`。
- 组合：`l_N3=l_vf+l_λ`（工程推荐，需 costate）；`l_N4=l_vf+10²·l_H+l_u`（**不需 costate，数据可用直接法生成**，更易落地）。

### 4.6 参数与性能
- 名义：`m0=1500kg, Isp=3800s, c1=0.33N`，t_f*=1.376yr，推进剂 210.47kg。
- 训练：AMSGrad(β₁=.9,β₂=.999,ε=1e-8)、batch 4096、分集 80/10/10、名义轨迹不训练。
- 性能：推力幅值误差 ≤5%、方向 ≤1°、价值（推进剂）误差 **<1%**；名义下仅多耗约 **2h** 推进剂。
- F/G 库扰动：`δm:σ=0.01, δλp=5.0, δλf=δλg=1.0, δλh=δλk=0, δλL=δλmf=0`。
- 自愈判据 **rEd** = 末 5 根数到目标轨道根数之 2-范数；A16 级扰动（rEd>0.01 不可达）触发重解/补样本。

> **→ MGA 落地点**：`MGASelfHealingEngine` 用价值网络/梯度给内层低推力转移作**伴随初猜**（改架势后免重解 TPBVP）；自愈库样本来源=BGOE 反向生成；rEd 作触发阈值；`l_N4` 可免 costate。

## 5. 模块 A｜多岛微分进化《The Generalized Island Model》(Springer 2012)｜无 PDF 摘要

- 把优化问题划分为若干独立并行演化子岛（可承载不同进化算法），通过环形拓扑异步交换染色体。
- 三迁移机制：① **注入 injection**（外部自治物种送入）、② **饱和 saturation**（满仓吞吐）、③ **反馈 feedback**（污染模拟）。
- 作用：攻克**早熟收敛与局部极值陷阱** —— 对应到 `MGAArchipelagoOptimizer` 的 `IslandCount`（默认 4）、`MigrationPeriod`（10 代）、`MigrationEliteCount`（Top 2）、`IslandTopology=Ring`，以及**废除 45 天/6 片截断**的全时域切岛。
