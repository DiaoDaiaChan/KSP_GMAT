# An Inflationary Differential Evolution Algorithm for Space Trajectory Optimization
**用于空间轨迹优化的膨胀差分进化算法 (IDEA)**

* **论文标识**: arXiv:1104.4731v1 [cs.CE], 25 Apr 2011 / IEEE Transactions on Evolutionary Computation
* **作者**: Massimiliano Vasile, Edmondo Minisci, Marco Locatelli
* **研究机构**: University of Strathclyde, University of Glasgow, Università degli Studi di Parma
* **核心贡献**: 建立了差分进化（DE）的离散动力系统（Agent Dynamics）统一数学表征；证明了在特定收缩条件下 DE 向不动点收敛的概率收敛性；提出了结合局部收敛球体膨胀与全局引导重启的**膨胀差分进化算法 (IDEA, Inflationary Differential Evolution Algorithm)**，在欧空局 Rosetta 等极其困难的深空引力助推轨迹优化中实现了显著超越标准 DE 的收敛率与鲁棒性。

---

## 一、问题背景与传统 DE 在深空轨迹中的困境

深空多引力助推（MGA）航迹问题（如 ESA Rosetta 彗星探测探测任务）存在极度复杂的开普勒非线性共振结构。标准 DE 算法（如 DE/rand/1/bin 或 DE/best/1/bin）在处理此类问题时，极易陷入两大困境：
1. **过早停滞 (Stagnation Without Convergence)**: 种群并未收敛于最优解，但由于差分扰动矢量幅值过小或方向坍缩，无法产生更优的变异个体，导致搜索完全停滞；
2. **欺骗性局部极小陷阱 (Deceptive Local Optima)**: 高度非线性的 Lambert 多圈解在某些相位会形成“虚假低能假象”，标准算法一旦涌入该区域便无法自拔。

## 二、Agent Dynamics: 差分进化的离散动力系统表征

论文将种群中的每个候选解向量 $\mathbf{x} \in \mathcal{D} \subset \mathbb{R}^d$ 视为一个具有速度和位置的智能体（Agent），建立通用离散时滞动力系统：

### 1. 动力系统基本方程
$$\begin{aligned}
\mathbf{v}_{i, k+1} &= (1 - c)\mathbf{v}_{i, k} + \mathbf{u}_{i, k} \\
\mathbf{x}_{i, k+1} &= \mathbf{x}_{i, k} + \nu \cdot \mathcal{S}(\mathbf{x}_{i, k} + \mathbf{v}_{i, k+1}, \mathbf{x}_{i, k}) \cdot \mathbf{v}_{i, k+1}
\end{aligned}$$

其中：
- $k$: 演化代数（离散时间步）；
- $c \in [0, 1]$: 阻尼粘性系数（Dissipative Coefficient）；
- $\nu$: 速度限幅缩放因子：
  $$\nu = \frac{\min(v_{\max}, \|\mathbf{v}_{i, k+1}\|)}{\|\mathbf{v}_{i, k+1}\|}$$
- $\mathcal{S}(\mathbf{y}, \mathbf{x})$: 贪婪选择算子（Selection Operator）：
  $$\mathcal{S}(\mathbf{y}, \mathbf{x}) = \begin{cases} 1, & \text{若 } f(\mathbf{y}) < f(\mathbf{x}) \\ 0, & \text{其他} \end{cases}$$
- $\mathbf{u}_{i, k}$: 控制项（变异与交叉生成的新方向）：
  $$\mathbf{u}_{i, k} = \mathbf{e} \odot \left[ (\mathbf{x}_{i_3, k} - \mathbf{x}_{i, k}) + F(\mathbf{x}_{i_2, k} - \mathbf{x}_{i_1, k}) \right]$$
  其中 $\mathbf{e}$ 为二项式交叉掩码向量：
  $$e_j = \begin{cases} 1, & \text{若 } r_j \le CR \text{ 或 } j = j_{\text{rand}} \\ 0, & \text{其他} \end{cases}$$

### 2. 退化与标准 DE 的等价性
当令粘性参数 $c = 1$、限幅 $v_{\max} = \infty$（即 $\nu = 1$）时，动力学方程退化为经典差分进化：
$$\mathbf{x}_{i, k+1} = \mathbf{x}_{i, k} + \mathcal{S}(\mathbf{x}_{i, k} + \mathbf{u}_{i, k}, \mathbf{x}_{i, k}) \cdot \mathbf{u}_{i, k}$$
- 若 $i_3$ 随机选择，则对应 **DE/rand/1/bin**（探索性强）；
- 若 $i_3 = i_{\text{best}}$，则对应 **DE/best/1/bin**（向当前最优强收缩）。

## 三、不动点与收缩映射证明 (Fixed Points & Convergence)

论文对动力系统（特别是 $i_3 = i_{\text{best}}$ 的收敛模式）进行了数学严格性证明：

### 定理：不动点收缩性 (Fixed-Point Contraction)
设目标函数在局部凸邻域内，且变异因子 $F$ 满足：
$$0 < F < \frac{1}{2}$$
在连续无改善迭代中，智能体相互之间的最大欧氏距离满足收缩不等式：
$$\max_{i, j} \|\mathbf{x}_{i, k+1} - \mathbf{x}_{j, k+1}\| \le \gamma \max_{i, j} \|\mathbf{x}_{i, k} - \mathbf{x}_{j, k}\|, \quad 0 \le \gamma < 1$$
**推论**:
种群将以概率 1 坍缩为一个点（不动点 $\mathbf{x}^*$）。一旦种群半径 $R_{\text{pop}} < \varepsilon_{\text{tol}}$，DE 便彻底丧失全局探索能力。

## 四、膨胀差分进化机制 (IDEA 算法架构)

为了克服这种不动点坍缩停滞，论文提出了 **IDEA (Inflationary Differential Evolution)**：

```
                      ┌──────────────────────┐
                      │ 全局随机/启发式采样  │
                      └──────────┬───────────┘
                                 │
                                 ▼
                      ┌──────────────────────┐
           ┌─────────►│  DE 动力学局部演化   │◄─────────┐
           │          └──────────┬───────────┘          │
           │                     │                      │
           │           种群半径 R < ε 判定?             │
           │                     │                      │
           │              是 ────┴──── 否               │
           │             │            │                 │
           │             ▼            └─► 继续代数演化 ─┘
           │  ┌──────────────────────┐
           │  │ 局部极值精炼 (Local) │
           │  └──────────┬───────────┘
           │             │
           │             ▼
           │  ┌──────────────────────┐
           │  │  膨胀禁忌球体 (Infl) │ (定义排斥禁区，避免重复浪费)
           │  └──────────┬───────────┘
           │             │
           │             ▼
           │  ┌──────────────────────┐
           └──┤  引导重启 (Restart)  │ (保留精英种子，其余在禁区外均匀投点)
              └──────────────────────┘
```

### 核心步骤：
1. **收敛与停滞检测 (Stagnation Detection)**:
   计算种群离差半径：
   $$R_{\text{pop}} = \frac{1}{N} \sum_{i=1}^{N} \|\mathbf{x}_i - \mathbf{x}_{\text{best}}\|$$
   当 $R_{\text{pop}} < \delta_{\text{stop}}$ 时，判定本轮演化已锁定局部吸引盆地。
2. **局部高精提取**: 对当前 $\mathbf{x}_{\text{best}}$ 运行局部单纯形或梯度打靶。
3. **膨胀排斥区 (Inflation Region)**:
   将以该解为中心、半径为 $r_{\text{infl}}$ 的超球体定义为禁区：
   $$\mathcal{B}(\mathbf{x}_{\text{best}}, r_{\text{infl}}) = \{ \mathbf{x} \in \mathcal{D} \mid \|\mathbf{x} - \mathbf{x}_{\text{best}}\| \le r_{\text{infl}} \}$$
4. **引导重启 (Guided Restart)**:
   保留历史最优集合中的精英代表，将其余个体在未膨胀禁区外的空间重新均匀采样，阻断对相同伪极值的无谓消耗。
