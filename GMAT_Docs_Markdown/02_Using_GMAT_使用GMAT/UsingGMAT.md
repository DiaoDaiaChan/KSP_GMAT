Using GMAT
The Using GMAT chapter contains high level and introductory information on
the sytem. If you need information on how to install and run the system, would
like a tour of the system, want know how to configure data files, or how GMAT
is organized, start here.
The Using GMAT section provides general information on GMAT and how to
use the software.
The Welcome to GMAT contains a brief project and software overview, including
project status, licensing, and contributors.
The Getting Started section describes how to get and install GMAT, how to run
the provided samples, and where to turn for further help.
The Tour of GMAT is an in-depth guide through some of the key interface
features, including the Resources tree, Mission tree, Command Summary, and
Script Editor.
Note
We consider the User Interfaces Overview section to be
essential reading, as it describes some fundamental aspects of
how GMAT works.
